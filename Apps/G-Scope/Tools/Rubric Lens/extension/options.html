RUBRIC LENS / G-SCOPE

Rubrics and prepared suggestions.

G-Scope performs the AI grading locally. Lens saves rubric exports and helps you apply reviewed suggestions in Gradescope.

Save a rubric

Open Create Rubric directly at gradescope.com, choose Grid View, and scroll through the questions. Click Lens → Extract rubric. Review the preview below the saved-file notice, then Confirm and save. The first click reads only. No pairing or AI connection is needed. The title defaults to course - assignment - semester unless you type your own.

Exports are saved under G-Rater/Rubrics inside Chrome’s download folder. G-Scope copies valid exports from your Windows Downloads/G-Rater/Rubrics folder into its managed Rubric Folder when you refresh saved rubrics. If Chrome uses a custom download location, upload the saved file in G-Scope.

Apply suggestions

Load / manage prepared suggestions JSON. On the Gradescope grading page, use Load / link batch, check the regions and explicitly accept each suggestion.

Legacy screen-by-screen AI requests and connector pairing are no longer used. Chrome may ask you to approve its Downloads permission when updating Lens.

Automatic saving

Files use compact titles, such as Math135-Exam1-Fall2026.json. G-Scope displays the full title inside the JSON. If Chrome opens a save dialog, turn off Ask where to save each file before downloading at chrome://settings/downloads. This setting affects all Chrome downloads. Leave the default location at Downloads; Lens adds G-Rater/Rubrics.
