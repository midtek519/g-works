Windows desktop shell

The everyday Windows launcher opens the desktop app. Use File > Open Browser
Version to use the same local service in a browser. Closing the desktop leaves
the local service and any active PDF builds running.

Back and Forward restore workspace views and filters. Settings opens the forms
available in this edition. File centralizes output folders. Window controls the
reusable PDF preview, preview pinning and full screen (F11; Esc exits). Help
contains version, changelog and technical information.

The desktop uses Microsoft Edge WebView2 and the bundled Python runtime.
Window state and its separate browser profile live in Data/Desktop. Earlier
G-Keeper desktop profiles are copied once and retained as recovery copies.
Desktop error logs live in Temp/Desktop. Private module data stays local and
is available only in G-Keeper. G-Whiz remains a Math 135 Materials-only app.

Mac uses the browser launcher; the Windows shell is not a Mac desktop build.
Runtime licenses are included in Dependencies/DesktopRuntime.
